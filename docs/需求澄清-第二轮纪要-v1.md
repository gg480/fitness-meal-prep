## 二、Apple Watch 可行性调研结论（后台调研，2026-11-24）

- **PWA Web Push**：iOS/iPadOS 16.4 起「添加到主屏幕」的 Web App 支持 Web Push（APNs，无需开发者账号），通知自动镜像到配对 Apple Watch；18.4 又加免 Service Worker 的 Declarative Web Push。来源：webkit.org/blog/13878、webkit.org/blog/16535
- **Web Bluetooth**：iOS Safari 全版本不支持，网页读 BLE 心率带（0x180D）不可行。来源：caniuse.com/web-bluetooth
- **快捷指令**：时间自动化 +「开始计时器/显示通知」动作可兜底离线提醒；表盘复杂功能仅原生 App 可做（本约束下排除）。
- **最优路径**：PWA（加主屏）+ 服务端准点 Web Push。限制：WebKit 无本地预约通知（倒计时须服务端准点推）、须完成「加主屏+授权」两步、用户用非 Safari 浏览器时此路线进一步打折。
- **用户既有决定**：完全没有 Mac、不打算搞原生；原生不可行则暂缓 → 本轮只出评估报告，不实施。
